Uber Clone – Responsive Web App (Bootstrap)

- Project Overview(🚗):
This project is a responsive Uber-inspired web application that allows users to either book a ride or register as a driver to earn money. Developed using HTML5, CSS3, and Bootstrap, the site replicates the look and feel of Uber’s official platform while maintaining clean, modern, and fully responsive design principles.
It’s optimized for both desktop and mobile views, offering a user-friendly interface that adapts to any device. The project serves as a front-end-only clone, great for demonstrating UI/UX skills, layout responsiveness, and design consistency across screen sizes.

- Key Features(🚀):
* Two Main Actions – “Get a Ride” or “Earn by Driving”
* Responsive Design – Mobile-first layout using Bootstrap Grid
* Clean UI/UX – Inspired by the real Uber website
* Mobile Optimization – Fully functional layout on phones and tablets
* Component Reusability – Reusable UI sections like navbar, hero banner, cards
* Navigation Bar – Sticky top navigation for quick access
* Call to Action Sections – Clear messaging to convert users or drivers

- Tools & Technologies:
HTML5 | CSS3 | Bootstrap | Version Control – Git & GitHub for code management | Bootstrap
